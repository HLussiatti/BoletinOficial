# Archivo histórico

Estos archivos documentan la exploración inicial, el plan y las validaciones
realizadas hasta septiembre de 2026. Describen el estado del proyecto en las
fechas indicadas y no son instrucciones vigentes de operación.

- `prototipo_2025/`: scripts, notebook y libro Excel del prototipo anterior.
  El aplicativo actual se implementa en `../src/epe_boletin/`.
- `PLAN_DE_TRABAJO.md`: diagnóstico y plan inicial del 11/09/2026.
- `ESTADO_IMPLEMENTACION.md`: avance registrado el 14/09/2026.
- `estilo_web.md`: primera propuesta visual; la referencia vigente es
  `../estilo_web_v2.md` junto con `../DESIGN.md`.
- `validaciones/`: informes de pruebas de fechas y de datos reales.

Los PDF, capturas y bases utilizados para esas verificaciones se guardan sólo
en esta instalación, bajo `../var/pruebas/` y `../var/historico/`. La carpeta
`var/` está excluida de Git: esas evidencias no se distribuyen con el repositorio.
La base de trabajo actual sigue en `../var/operacion/`.

La organización y las decisiones de limpieza se registran en
`../MANTENIMIENTO.md`.
